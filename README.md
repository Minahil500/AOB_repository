 **AOB Repository**

A web-based application for managing legal documents and regulations. The system provides document uploading, OCR-based text extraction, regulation management, user management, profile settings, and document processing functionalities.

 **Features**

1. User authentication with Login and Logout
2. User management — Create, View, Edit, and Delete users
3. Regulation management — Create, View, Edit, and Delete regulations
4. PDF and document upload and processing
5. OCR-based text detection and extraction
6. Document conversion and temporary image generation
7. Profile management and password change
8. Password generation functionality
9. Application settings management
10. Database integration using SQL

**Project Structure**

1. **OCR** — OCR text detection and document processing files.
2. **Profile** — User profile and password management files.
3. **Regulations** — Files for creating, viewing, editing, and deleting regulations.
4. **Settings** — Application settings and configuration files.
5. **Temp Images** — Temporary images generated during document conversion.
6. **Uploads** — Uploaded files and documents used for processing and conversion.
7. **Users** — Files for creating, viewing, editing, and deleting users.
8. **SQL** — Database structure, tables, and queries.
9. **Login / Logout** — User authentication and session management.
10. **Generate Password** — Password generation functionality.

** Technologies Used**

1. PHP
2. MySQL
3. HTML
4. CSS
5. JavaScript
6. OCR
7. SQL

## Purpose

The purpose of this project is to provide a centralized platform for efficiently managing legal documents and regulations. It simplifies document processing, text extraction, user management, and regulation management through an integrated web-based system.
